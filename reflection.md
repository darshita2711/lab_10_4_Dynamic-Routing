# Dynamic Routing Blog Application – Reflection

## What I Learned

In this project, I learned how to use React Router to navigate between different pages in a React application. I practiced creating routes, using dynamic URL parameters with `useParams`, and navigating between pages using `Link`.

I also learned how to use Context API to manage authentication state and how to protect pages using a custom ProtectedRoute component.

## Challenges I Faced

One challenge was understanding how dynamic routing works and how React Router reads parameters from the URL.

Another challenge was understanding Context API and how to share authentication state between components like Navbar, Login, and Admin.

## How I Solved Them

I broke the project into smaller steps and tested each feature in the browser. I practiced using `useParams`, `useContext`, and `Navigate` to understand how they work together.

## What I Enjoyed

I enjoyed building the blog navigation and seeing how clicking different post links opens the correct post without reloading the application.

## What I Want to Improve

I want to improve my understanding of React Router, Context API, and authentication. I also want to practice building more complex React applications with better styling and functionality.
